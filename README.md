# Neon Pulse — Chat Multistream para Streamlabs

Chat personalizado gratuito para Streamlabs, criado para deixar o chat da live mais bonito, legível e com identidade visual diferente para cada plataforma.

## Recursos

- Chat multistream em um único widget
- Identificação visual por plataforma
- Kick com identidade verde
- Twitch com identidade roxa
- YouTube com identidade vermelha
- Facebook com identidade azul
- Nome do espectador mantendo a própria cor
- Suporte a badges
- Suporte a emotes e imagens
- Glow neon dinâmico
- Fundo transparente para uso no OBS
- Personalização simples pelo CSS

## Arquivos

O projeto possui 3 arquivos principais:

- `HTML - Neon Pulse.txt`
- `CSS - Neon Pulse.txt`
- `JS - Neon Pulse.txt`

Cada arquivo deve ser copiado para a aba correspondente do Chat Box personalizado do Streamlabs.

## Como instalar

1. Acesse o Chat Box da Streamlabs.
2. Ative a opção de HTML/CSS personalizado.
3. Abra as abas HTML, CSS e JS.
4. Substitua o conteúdo de cada aba pelo código correspondente deste projeto.
5. Salve as alterações.
6. Adicione o Chat Box ao OBS como fonte de navegador.

## Personalização

No início do arquivo CSS existe uma área chamada:

`PERSONALIZE SEU CHAT AQUI`

Nela você pode alterar facilmente:

- tamanho do nome
- tamanho da mensagem
- arredondamento dos cards
- transparência
- espaçamento
- cores das plataformas
- intensidade do glow

Não é necessário entender programação para fazer as personalizações básicas.

## Compatibilidade

O Neon Pulse foi desenvolvido para o Chat Box personalizado da Streamlabs.

O projeto possui suporte visual preparado para:

- Kick
- Twitch
- YouTube
- Facebook
- X / Twitter

A disponibilidade de cada plataforma depende das integrações oferecidas pela Streamlabs.
